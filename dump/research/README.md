# Research Memory

这里保存经过授权、去标识化的用户研究记录。不要保存真实姓名、API Token、密码、完整窗口标题或与研究无关的私密内容。

## 文件命名

```text
YYYY-MM-DD-participant-code-topic.md
```

## 访谈模板

```markdown
# Interview — YYYY-MM-DD — Participant code

## Context
- Persona:
- Current tools:
- Observation period:

## Verbatim signals
> 用户原话

## Behaviors observed
- 只记录实际发生的行为

## Interpretation
- 当前解释：
- 置信度：low / medium / high

## Counter-evidence
- 哪些证据不支持当前解释

## Decisions affected
- Decision ID：
- PRD Requirement ID：

## Follow-up
- 下一次需要验证什么
```

每次研究结束后，将稳定结论同步到上层文档，并在 [`../06-decision-log.md`](../06-decision-log.md) 中更新对应假设；不要让研究结果只停留在单次访谈文件里。
